지혜의 낭독 자동 업로드

‘지혜의 낭독’ 채널 운영자가 본인의 PC에서 영상 파일을 YouTube에 업로드하고 제목, 설명, 썸네일, 재생목록과 처리 상태를 관리하기 위한 개인용 프로그램입니다. 일반 이용자의 계정 연결을 모집하지 않습니다.

개인정보처리방침

프로그램은 운영자가 Google에서 승인한 YouTube 관리 권한으로 채널 식별 정보와 영상 상태를 조회하고, 운영자가 지정한 영상·썸네일·제목·설명 및 재생목록 정보를 YouTube API에 전송합니다.

Google 로그인 비밀번호는 이 프로그램이 수집하거나 저장하지 않습니다. OAuth 연결 토큰은 운영자의 Windows 사용자 계정에 연결된 DPAPI로 암호화하여 로컬 파일로 보관합니다. 파일을 OneDrive 등 동기화 폴더에 두면 암호화된 파일이 해당 동기화 서비스에도 복사될 수 있습니다.

인증 정보는 채널 관리와 연결 유지에만 사용합니다. 이 업로드 프로그램은 데이터를 판매하거나 광고 용도로 제공하지 않으며, Google API 통신 외에 별도의 분석 서버로 전송하지 않습니다. 로컬 작업 기록에는 업로드 영상 ID와 처리 결과가 저장됩니다.

운영자는 Google 계정 연결 관리에서 권한을 취소할 수 있습니다. 권한 취소는 이미 업로드된 영상을 삭제하지 않습니다. 로컬 인증 파일과 작업 기록의 삭제는 운영자가 별도로 관리합니다.

이 방침의 범위는 자동 업로드 프로그램입니다. 음성·이미지 등 제작 도구의 데이터 처리는 각 도구의 정책을 따릅니다.

이용 안내

이 프로그램은 채널 운영자 본인의 콘텐츠 관리용입니다. 운영자는 업로드할 콘텐츠의 권리와 정확성, YouTube 정책 준수 여부를 확인합니다. 업로드 결과는 YouTube의 처리 상태 및 API 제한에 따라 달라질 수 있습니다. 현재 구현은 비공개 업로드만 허용합니다.
